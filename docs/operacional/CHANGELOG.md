## [1.2.0] — 2026-07-22 — Estabilização e Conclusão Full-Stack da v1

### Adicionado
- **Export final de quadrinhos (P1)**: novo serviço `comic_export_service.py` + endpoints `POST/GET /jobs/{id}/comic-export`. Monta CBZ de staging determinístico a partir das páginas visuais finalizadas (prioridade `finished_pages` → `final_pages`, validadas arquivo a arquivo com PIL, contagem, ordem do manifest, duplicatas lógicas e extensão agnóstica PNG/JPEG) e gera o EPUB via KCC com título/autor (`-t`/`-a`). Export atômico (staging temporário → validação → `os.replace` → manifest por último). Manifest `comic_export/comic_export_manifest.json` v1 com proveniência por página (`selected_variant`, `origin`, `visual_translation_applied`) e estado agregado `translation_state` (full/partial/none/not_applicable). **`input_path` nunca é usado como fallback** — fonte ausente/incompleta responde 409 estruturado com `next_step`.
- **Política de envio ao Kindle sem fallback ao original**: documento → `epub_path`; comic sem pipeline visual (caminho rápido consciente) → EPUB do KCC-original; comic com tradução concluída OU pipeline visual iniciado → **exige** export final (`comic_export_status='done'` + EPUB validado dentro de `storage/output/{id}/comic_export/`), senão 409 `COMIC_EXPORT_REQUIRED`. Download/envio validam arquivo regular contido no diretório do job (sem path arbitrário do banco).
- **Página Exportar (P2)**: nova rota `/export/:id` (`ComicExportPage`) como etapa final do pipeline comic — resumo da fonte, estado real da tradução por proveniência, metadados editáveis, formatos EPUB+CBZ, pré-requisito bloqueado com CTA, progresso honesto, download e envio. Sidebar reordenada: Análise → Tradução → Revisão → Overlay → Curadoria → Acabamento → Consistência → **Exportar** (antes, "Exportar" apontava para o Acabamento).
- **`GET /jobs/{id}/pipeline-state`**: fonte única de gating por etapa (done/available/blocked + motivo + pré-requisito) derivada dos manifests; sidebar desabilita etapas bloqueadas com tooltip do motivo; Consistência nunca bloqueia o Export.
- **Modo Recomendado (P3)**: `comic_quick_pipeline_service.py` + `GET .../comic-quick-pipeline/preflight` (validação sem efeitos: engine/par de idiomas, OCR, páginas extraíveis, KCC, disco, operação ativa, artefatos reaproveitáveis) + `POST .../comic-quick-pipeline` (tradução → revisão auto-aprovada consentida → overlay → render → curadoria automática `render_overlay` + export de páginas). NÃO exporta o EPUB — confirmação do usuário na etapa Exportar. Jobs comic novos nascem com `flow_mode='recommended'`; jobs antigos preservam `advanced`; alternar modo nunca apaga artefatos. Painel na AnalysisPage com resumo, confirmação explícita e progresso.
- **Progresso por operação (P4)**: `progress_service.py` com `operation_id`, arquivo `progress/{op}.json` atômico, heartbeat, `boot_id`; coluna `active_operation`; recuperação de órfãs pós-restart (marca `interrupted` + mensagem, libera retry — sem 409 eterno); rejeição de concorrência com lock intra-processo (dois cliques → 409 `OPERATION_IN_PROGRESS`); cancelamento cooperativo `POST /jobs/{id}/operations/{op}/cancel` (checado entre páginas; processos externos KCC/Calibre/OCR não são interrompidos — limitação documentada); progresso real por página na tradução comic (`N de M`), por chunk na tradução de documento, indeterminado honesto para Calibre/KCC/OCR; `GET /jobs/{id}/status` passa a incluir `progress` + `phase` canônica (`derive_phase`, sem renomear estados no banco); `ProgressBar` determinada/indeterminada no frontend; timeout de polling vira aviso "processamento continua no backend" + reconexão (sem falha falsa).
- **Colunas novas** (migração inline idempotente, dados preservados): `comic_export_status/path/source/error`, `flow_mode`, `active_operation`; teste de upgrade sobre banco antigo.
- **Testes**: +57 backend (`test_comic_export.py` 31, `test_comic_quick_pipeline.py` 7, `test_progress_service.py` 14, pipeline-state 3, OCR-block 2) e +16 frontend (`ComicExportPage` 10, `RecommendedModePanel` 6). Total: 478 backend / 228 frontend.

- Build TS quebrado (import `Palette` órfão; `boolean|null` em `disabled`) e 7 testes de baseline desatualizados em relação ao redesign de 08/abr (Button `action-blue`, MetricsPage, badge Manual, serve path de `_save_page_images` com fallback para bytes originais).

- KCC rápido claramente rotulado como "Converter original via KCC" com aviso e link para a etapa Exportar; para comic com tradução, o CTA de envio da AnalysisPage leva à etapa Exportar.
- Mensagem de bloqueio OCR acionável (o que instalar, como reprocessar via duplicação no Histórico) com detalhe técnico recolhido em área secundária.
- Job fantasma no localStorage: Layout valida o job via API no refresh e limpa o contexto em 404.
- Corrida TOCTOU no disparo simultâneo de operações (dois cliques registravam duas operações).
